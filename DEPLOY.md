# Deploy Motiveoflife on GitHub Pages

1. Go to https://github.com/tanujkapila/motiveoflife
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Open the **Actions** tab and wait for the Pages build/deployment to complete.
6. Visit https://tanujkapila.github.io/motiveoflife/

If the URL returns a 404, check that Pages is enabled and that `index.html` is at the repository root. GitHub Pages can take several minutes to publish after the first setup.
